# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | No — please upgrade to the latest version |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities by emailing **niels.tanis@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected version(s)

You can expect:

- **Acknowledgement** within 3 business days
- **Status update** within 7 business days (confirmed, needs more info, or not a vulnerability)
- **Fix and disclosure** coordinated with you once a patch is ready

Security fixes are released as patch versions and noted in [CHANGELOG.md](CHANGELOG.md).
